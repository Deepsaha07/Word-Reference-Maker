WordRef Support

WordRef is a Microsoft Word add-in for managing BibTeX references, inserting citations, and automatically generating bibliographies.

Basic Troubleshooting

1. Add-in does not load

  • Close and reopen the WordRef task pane.
  • Restart Microsoft Word completely.
  • Check that you are connected to the internet.
  • Ensure Microsoft Word is updated to the latest version.

2. Buttons are not responding

  • Click the Reload button inside the add-in.
  • Wait a few seconds after opening the task pane before clicking buttons.
  • Reopen the document and try again.

3. Citation was not inserted

  • Make sure the cursor is placed inside the document body before inserting citations.
  • Avoid inserting citations inside headers, footers, or protected sections.
  • Try clicking directly into a paragraph and insert again.

4. Bibliography is not updating

  • Click the Update Bibliography button.
  • Ensure at least one citation exists in the document.
  • Try changing the citation style and updating again.

5. Imported BibTeX is not recognised

  • Ensure the BibTeX format is valid and starts with entries such as @article{} or @inproceedings{}.
  • Remove unsupported or malformed fields if parsing fails.
  • Try importing one BibTeX entry at a time to isolate formatting issues.

6. Duplicate references detected

  • WordRef automatically skips duplicate citation keys.
  • Ensure imported entries use unique BibTeX citation keys.

7. Add-in appears blank or frozen

  • Close the task pane and reopen it from the Word ribbon.
  • Restart Microsoft Word.
  • Clear Office cache if the issue persists.

8. Export or import is not working

  • Check browser or Office permissions for downloads.
  • Ensure the selected import file is valid JSON, CSV, XML, or BibTeX.
  • Try exporting again after reloading the add-in.

9. Microsoft Word compatibility

  • WordRef is designed for Microsoft Word with Office Add-ins support.
  • Some older desktop versions may not fully support advanced citation controls.

10. Still need help?

Contact support via email or open an issue on GitHub with:

  • A short description of the issue
  • Steps to reproduce the problem
  • Screenshots if available
  • Your Microsoft Word platform/version
